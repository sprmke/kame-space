# Page inventory (v3)

Every route and global overlay, with its phone target. Companion to [`mobile-native-app-redesign.md`](./mobile-native-app-redesign.md) and [`mobile-native-app-redesign-design-system.md`](./mobile-native-app-redesign-design-system.md).

**Columns.** _Family_: pattern from design-system §7 (F1 Today, F2 List, F3 Detail, F4 Data, F5 Settings, F6 Create sheet, F7 Conversation, F8 Flow, F9 Discovery, F10 Status, F11 Tool chrome, F12 Hub). _Mockup_: concept letter. _Kame / mascot_: role from design-system §11 and §12, or "none" (empty states always allowed within budget and not repeated here). _Tab_: active tab from `tabForRoute`. _Ph_: phase in the plan.

**Before building any row:** fill its parity table in the route guide (`docs/guides/routes/**`). The "Must keep" notes below are reminders, not the full inventory.

Source of truth for routes: `ui/src/features/**/routes/*.tsx`, `ui/src/features/dashboard/org/routes/index.tsx`, `adminSidebarNav.ts`, `superAdminPlatformNav.ts`. Re-run the route extraction in Phase 0 to catch anything added since 2026-11-20.

Blockers and major issues

IDSevFindingFix
M-01P0 Guest starting a chat from a listing fails with 400 "Failed to upsert conversation" when a web conversation already exists for that guest and property. Resolve by (property_id, guest_user_id) on 23505 instead of retrying the same insert.
M-10P0 On phones the platform tabs are crushed by the sync pill. Instagram is off-screen and unreachable. Give tabs the full row on phone; move or collapse the sync pill.
M-11P1 Quick Access FAB covers the composer Send button and the last thread row. Offset the composer or hide the FAB on composer routes.
M-12P1 Guest Messages hub is taller than the phone viewport, so the composer is below the fold and the header scrolls away. Size from the real chrome height; sticky thread header.
M-03P1 A zero-result search says "No messages yet." on the Chat tab. Check search before the platform empty branch.
M-04P1 Quick reply Delete is instant, org-wide, no confirm. Confirm with the reply title; offer undo.
M-05P1 Realtime deltas ignore the active platform or status filter. Apply filter predicates inside patchThreadRows.
M-06P1 "Importing chats" never clears when last_sync_at is null. Age the state out, or treat an imported list as complete.
M-02P1 Raw server error text shown to guests. Friendly copy plus support link; keep detail in logs.
M-21..23P1 Host composer has no accessible name; several phone controls are 32 to 36 px. Label the textarea; finish the 44 px pass.

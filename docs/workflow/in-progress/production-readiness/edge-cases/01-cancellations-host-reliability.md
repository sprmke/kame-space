# Cancellations and host reliability (`CAN`)

**Owned elsewhere:** the policy engine, booking-time snapshot, guest cancel and request flows, refund calculator and cases E1 to E49 live in [`cancellation-policy-and-process.md`](../../cancellation-policy-and-process.md). This file covers what that plan leaves open: **what stops a host from cancelling on a guest, and what protects the guest when they do.**

## How it works today

- `cancel-booking` lets anyone with `bookings.detail.workflow:edit` cancel at any status in `HOST_CANCELLABLE_STATUSES`, which includes `READY_FOR_CHECKIN` on arrival day and `READY_FOR_CHECKOUT` mid-stay (decision D6). There is no lead-time check.
- Host-initiated cancels default to a 100% refund of cash paid. Refunds are paid by the host by hand and recorded in `booking_refunds`.
- The guest is emailed (`booking_cancelled_guest`) unless the host unticks "Notify guest". No push, no chat message, no in-app notice on the trip page beyond the cancelled state.
- The only consequence for the host is the Superhost cancellation rate (`superhostMetrics.ts`, `cancelled_by = 'host'`).
- After a cancel, the orchestrator creates a "freed dates" marketing opportunity so the host can promote the same nights.

## How the big platforms handle it

Summary from public help pages; confirm exact fees and windows before quoting them to hosts.

| Platform    | Host cancels                                                                                                                                                                                                                                                                                                                                                           |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Airbnb      | Allowed, but: fee taken from the next payout (higher inside 48h / 30 days), the cancelled dates are **blocked** on the calendar so the host cannot rebook them, an automated review is posted, Superhost lost, repeated cancels can suspend the listing. Guest gets a full refund and rebooking help (AirCover). Waived only for documented extenuating circumstances. |
| Booking.com | Host must cover the price difference if the guest is relocated to a pricier place (relocation / "guarantee" policy). Repeated host cancellations hurt ranking and can close the property.                                                                                                                                                                              |
| Agoda       | Agoda customer service handles the guest and rebooking; property-side cancellations count against the property with Agoda.                                                                                                                                                                                                                                             |
| Vrbo        | Host cancellation fee plus calendar block for the cancelled dates; guest fully refunded.                                                                                                                                                                                                                                                                               |

## Decisions needed (Phase 0)

1. Lead-time tiers for host cancels (suggest: free friction above 7 days, confirm + alert inside 7 days, super-admin review inside 24h).
2. Does a host cancellation cost money (fee taken from parking payouts or added to the next subscription invoice), or only reputation?
3. Calendar block after host cancel: always, or unless the reason is a verified property emergency?
4. Do we post an automated listing note for host cancellations?

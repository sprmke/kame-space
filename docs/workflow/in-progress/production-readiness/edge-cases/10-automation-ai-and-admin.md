# Automation, AI actions and super-admin (`PLAT`)

**Owned elsewhere:** prompt-injection tests (PR-013), AI hardening checklist (PR-005), alert channels and named owners (PR-027), super-admin step-up QA (PR-086), cron secret parity (PR-022). The AI assistant's cancel path is CAN-16 in [`01-cancellations-host-reliability.md`](./01-cancellations-host-reliability.md).

This file covers the paths that change bookings or money **without a person clicking the normal button**: AI tools, client dev flags, crons, and super-admin actions.

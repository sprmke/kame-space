# OWASP API Security Top 10 (2023)

| ID    | Category                                        | Status | Notes                                                                                                                                                                                                                                                                     |
| ----- | ----------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API1  | Broken Object Level Authorization               | ✅     | Guest capability tokens enforced. 2026-11-24: `get-pay-parking` closed (bare booking id → redirect fields only; PII needs `?access=` HMAC or the signed-in owner). `check:auth-matrix` fails on any tenant function with no resource-scope check (378 functions, 0 gaps). |
| API2  | Broken Authentication                           | ✅     | Wrappers `serveAdmin`/`serveAuthenticated`/`serveSuperAdmin`/`serveCronPost`. Auth matrix 0 zero-signal. Adversarial live suite 16 cases.                                                                                                                                 |
| API3  | Broken Object Property Level Authorization      | ✅     | 2026-11-24: no handler spreads a raw request body into a write; `audit-edge-functions --check` now fails on `.insert(body)`/`.update(body)`/`.upsert(body)`. Per-handler strict Zod remains PR-018.                                                                       |
| API4  | Unrestricted Resource Consumption               | 🟡     | Public limits enforced; authenticated per-user limit is a super-admin runtime switch (default log-only). 2026-11-24: JSON bodies capped at 2 MB (`413`) and remote media downloads byte-capped. Enabling authenticated enforcement stays an operator action.              |
| API5  | Broken Function Level Authorization             | ✅     | Super-admin / org / property / parking catalogs; 23 platform-scoped super-admin functions classified explicitly in the auth matrix.                                                                                                                                       |
| API6  | Unrestricted Access to Sensitive Business Flows | 🟡     | Booking submit, payments, AI generate, invites. Turnstile enforced. Cost-weighted limits deferred to the service-cost plan (PR-021).                                                                                                                                      |
| API7  | Server Side Request Forgery                     | ✅     | 2026-11-24: `emailService` QR fetch and `marketingPosterDirector` photos go through `fetchFirstPartyOrPublic` (manual redirects, per-hop private-IP checks, byte caps). Guard blocks multicast/reserved literals; CI gate `check-outbound-fetch-ssrf.sh`.                 |
| API8  | Security Misconfiguration                       | 🟡     | CORS allowlist (`check-cors-origins.sh`), enforcing CSP, HSTS, `X-Frame-Options`. Operator items: Maps referrer lock, env secrets.                                                                                                                                        |
| API9  | Improper Inventory Management                   | 🟡     | 378 functions swept by `audit-edge-functions` + `audit-auth-matrix` in CI. Dead-function analysis (knip) deferred.                                                                                                                                                        |
| API10 | Unsafe Consumption of APIs                      | ✅     | Webhook signature verify + event-id dedupe (PayMongo, Meta, Resend, ops ingest); replay protected. iCal import host-allowlisted per hop.                                                                                                                                  |

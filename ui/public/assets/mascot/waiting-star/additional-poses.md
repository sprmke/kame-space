Created using the built-in image tool with the star-hug character as reference. The prompt specified six complete characters per sheet, four teal forehead spots, peach cheeks, cream belly, orange shell, tactile props, transparent background and soft contact shadows. Each cell was exported as a 448 × 468 PNG and losslessly optimized.

# Kame waiting with a star

One loading-state illustration and a three-second loop for review.

- `still.png` is a 384 × 384 transparent PNG, suitable as a reduced-motion fallback.
- `loading.gif` is a 384 × 384, 25 fps looping GIF on pale mint (`#edf7f2`).
- Motion moves the complete illustration vertically by eight pixels using a cosine cycle. Facial expression and limbs remain fixed.
- Suggested display size is 96–192 CSS pixels. Provide visible loading status text and use empty image alt text when that text communicates the state. Use the still when reduced motion is requested.

Generated with the built-in image tool using the existing `hello.png` as the character reference. Prompt requested a seated Kame hugging a plush gold star, four teal head spots, cream belly, peach cheeks, soft 3D rendering and transparent background. FFmpeg resized the still and rendered the GIF using palette generation and a smooth periodic vertical offset.

These assets are available for application integration. No route uses them yet.
